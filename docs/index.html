INSTALL

三步完成安裝

目前以 GitHub Release APK 發布，不需要 Google Play。

  1. 01
    下載 APK

    使用上方「下載 Android APK」取得最新正式版本。

  2. 02
    允許安裝未知來源 App

    Android 若跳出提示，僅需授權目前使用的瀏覽器或檔案管理器安裝。

  3. 03
    直接分享影片網址

    回到社群 App，點「分享」並選擇 Social Video Downloader。

PRIVACY

登入資料留在你的裝置

Session 資料使用 Android Keystore 保護並加密儲存在裝置本機。App 不會把登入 Cookie 上傳到開發者伺服器。

01

本機保存
Instagram、Threads、X Session 儲存在 Android 裝置。

02

可自行清除
不再需要登入狀態時，可從 App 的平台登入設定清除。

03

公開內容不強迫登入
可匿名解析時會優先使用不需帳號的流程。
